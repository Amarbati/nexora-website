# NEXORA — Digital Experience Website

A modern, responsive business website designed for NEXORA, a fictional digital experience company.

## Project Overview

NEXORA is a modern business website created to communicate the company's services, values, capabilities and contact information through a clean and responsive digital experience.

The website is designed for desktop, tablet and mobile users.

## Objectives

- Present NEXORA as a credible digital experience company
- Clearly communicate the services offered
- Explain the company's mission and vision
- Provide a simple and accessible contact experience
- Create a responsive and user-friendly website
- Demonstrate modern HTML, CSS and JavaScript skills

## Target Audience

The website is designed for:

- Startups
- Small and medium-sized businesses
- Organizations looking for digital solutions
- Businesses that need website and UI/UX services

## Design Approach

The website follows a clean and modern business design approach with:

- Strong typography
- Consistent spacing
- Reusable cards and buttons
- Clear visual hierarchy
- Responsive layouts
- Accessible form elements
- Mobile navigation

## Responsive Design

The website is designed to adapt to:

- Desktop screens
- Tablet screens
- Mobile screens

CSS media queries are used to adjust layouts, typography, grids and navigation for smaller screen sizes.

## Accessibility

Accessibility considerations include:

- Semantic HTML elements
- Descriptive navigation links
- Form labels
- Keyboard-friendly controls
- Visible focus states
- Readable text and contrast
- Accessible mobile navigation controls

## JavaScript Interactions

The project includes meaningful interactions such as:

1. Mobile navigation menu
2. Contact form validation
3. Form success feedback
4. Button interaction feedback
5. Dynamic footer year

## Contact Form Validation

The contact form validates:

- Full Name
- Email
- Service Required
- Message

The form provides inline error messages and a success message.

This is a front-end demonstration and does not connect to a backend server.
